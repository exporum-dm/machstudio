# 등록 탭 순서·대회 종료 후속 개선

- 등록 탭을 현황 → 기본 정보·폼/필드 → 설치 → 응답·현장 운영 → 분석 → 활동·관리 순서로 정렬했다. 빌더형과 연동형의 전용 탭 구분과 기존 URL 탭 ID는 유지한다.
- 대회 상세 상단에 진행 상태 선택과 종료 버튼을 노출했다. 종료와 재개는 확인을 받으며 기존 상태 변경 API를 이용한다. 종료해도 참가작·집계·공개 결과 링크는 보존한다.
- 본선 투표 마감 후 자동 단계가 본선에 머물던 문제를 수정했다. 투표 마감은 심사 중으로, 결과 공개는 발표 완료로 판정한다. 명시적인 수동 단계는 우선한다.
- 발표 완료·종료 대회는 진행 중 대시보드에서 제외하며 대회 목록에서는 계속 관리한다.
- 종료된 대회는 투표 조회에도 마감을 표시하고 투표 취소 요청도 차단한다. 결과 발행 시 상세 화면 상태도 즉시 갱신한다.
- 실제 운영 대회의 상태를 임의로 변경하지 않았다. 운영자가 상세 상단에서 종료할 수 있다.

검증: 상태·라운드 판정 10건, 등록 탭 구성 4건, 종료 취소·확정·재개 확인 3건 통과. TypeScript 검사 및 변경 코드 ESLint 통과. 최종 프로덕션 빌드는 Vercel 배포에서 확인한다.
